# 🧁 Projeto: Página de Receita

Este projeto consiste em uma página de receita de cupcake de café com chantilly, desenvolvido para praticar HTML e CSS, focando em estruturação semântica e estilização de layouts.

## 🔗 Acesse o site publicado:
👉 [Clique aqui para abrir a receita](https://thaiscalvi.github.io/Projeto-Pagina-de-Receita/)

## 📋 Sobre o Projeto

- Estruturado com **HTML semântico** (`<header>`, `<main>`, `<footer>`, `<section>`, `<article>`);
- Estilizado com **CSS3**;
- Layout responsivo e organizado;
- Conteúdo objetivo e visualmente agradável;
- Exercício para prática de construção de sites simples com design leve.

## 🎯 Aprendizados

- Estruturar páginas web com HTML semântico;
- Utilizar propriedades de CSS como `padding`, `margin`, `border-radius`, `background-color`, `box-shadow`, etc;
- Trabalhar com alinhamento e organização de elementos;
- Boa prática de separação entre estrutura (HTML) e estilo (CSS).

## 💡 Ideias futuras

- Implementar responsividade para dispositivos móveis;
- Adicionar outras receitas e criar uma navegação entre elas;
- Melhorar a estilização com animações sutis usando CSS.
